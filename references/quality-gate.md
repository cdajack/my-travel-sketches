# Quality Gate

交付前逐项检查。

## 输出边界

- [ ] 最终画面没有出现原照片、照片裁片、摄影背景或画中画。
- [ ] 没有左右或上下对照、前后对比、照片拼贴或分栏版式。
- [ ] 成品是重新雕刻的橡皮章图形，不是照片加滤镜。
- [ ] 多张输入照片各自生成独立成品，没有合并拼贴。

## 画幅与构图

- [ ] 用户未指定比例时，成品为 `3:4`（宽:高）竖版。
- [ ] 用户指定比例时，成品遵循该比例，而不是回退到默认值。
- [ ] 未明确要求大版时，章印位于画布左下区域，没有居中或擅自放大铺满。
- [ ] 小版时章印只占画布高度约 28%–38%，复杂场景也没有变成满版插画。
- [ ] 小版时章印上方和右侧有大面积温暖纸白；若用户明确要求大版或居中格式，则单幅章印水平居中、宽度约占画布的 50%–60%，并保留自然纸张边距。
- [ ] 小版时章印与文字作为一个左下内容组且文字左对齐；大版时文字位于章印下方并整体居中。
- [ ] 画面中只有一幅章印，没有复制、重复排列、阵列或无缝纹样。
- [ ] 没有相框、桌面背景或产品样机。

## 照片事实

- [ ] 主体身份、数量、姿态、建筑结构、地形、观察角度和方向可从输入照片追溯。
- [ ] 没有镜像、复制、拉伸、主体替换或凭空新增地标。
- [ ] 复杂场景已压缩为最有识别度的 1–3 个视觉锚点。

## 章印媒介

- [ ] 章印确实来自输入照片中的同一场景，并能一眼辨认。
- [ ] 场景已重组为可雕刻的线面，而不是照片加颗粒或单色滤镜。
- [ ] 使用 2–4 种照片取样专色，没有彩虹色和数字渐变。
- [ ] 可见缺墨、断边、针孔、颗粒、纸张透底与轻微错版。
- [ ] 没有水彩、铅笔、平滑矢量、塑料 3D 或通用纪念品图标感。

## 文字与交付

- [ ] 归档文字少、小、清楚，不出现乱码、品牌、网址或二维码。
- [ ] 文字紧接章印下方；小版所有行左对齐并与章印左边缘对齐，大版所有行整体居中。
- [ ] 用户未指定年份时使用当前年份；用户指定年份时使用指定年份，没有猜测照片拍摄年份或历史年份。
- [ ] 地名和坐标均有可靠依据；否则使用泛化标题。
- [ ] 成品已保存到工作区。
- [ ] 成品已经作为可见图片显示在聊天中。

任一核心项失败时，定向重做，不得把失败图作为完成结果交付。
