# Style System

## 这套风格在保存什么

输入照片负责提供事实；成品负责保存记忆中最难忘的形状。最终画面只有重新雕刻后的橡皮章小画，不展示照片本身，也不使用照片加滤镜。

## 画幅与版式

- 默认画幅：`3:4`（宽:高）竖版。
- 比例优先级：用户指定比例优先于默认比例。
- 背景：全画布为温暖、无涂层的旧纸，不添加相框、桌面或产品样机。
- 默认小版：章印与归档文字组成一个整体，锚定在画布左下区域，不居中、不铺满；章印位于文字上方，只占画布高度约 28%–38%，章印上方和右侧保留大面积未印刷纸白。
- 大版（仅用户明确要求“大版”或“居中格式”时启用）：画面中只放置一幅章印，水平居中，宽度约占画布的 50%–60%，四周保留自然纸张边距；文字置于章印下方并整体居中，保持少、小、准确。不得复制章印、重复排列、阵列或生成无缝纹样。
- 复杂主体在小版中必须通过删减细节适配小型章印尺度；大版也仍需保持可雕刻的线面关系，不能逐像素复制照片。
- 文字：紧接章印下方；小版所有文字左对齐，文字块左边缘与章印左边缘对齐；大版所有文字整体居中。

比例与占比是视觉目标，不要求像素级死卡。横版、正方形或超宽比例中，小版可以缩放内容组并调整边距，但必须保持“左下小章、下方左对齐文字、上方与右侧大片纸白”的版式关系；只有用户明确选择大版或居中格式时，才采用“单幅居中章印、下方居中文字”的版式。

## 内容提炼

先找视觉锚点，再雕刻：

- 建筑：屋顶、穹顶、塔楼、立面节奏、门窗比例。
- 山岸：地平线、山形、水岸、岩石负形、孤立船只或灯塔。
- 街景：道路方向、主要建筑、车辆或行人的姿态。
- 人物与动物：数量、轮廓、动作方向、服装主色、关键道具。
- 交通工具：车身、车头、车窗、行进方向和环境关系。
- 静物：整体轮廓、开口、把手、结构比例和标志性部件。

删除摄影光影、密集纹理、重复结构和无关杂物。主体必须一眼可辨，但不追求细节完整。原照片不得成为背景、纹理或版式组成部分。

## 印刷机制

章印采用 2–4 色手工套印逻辑：

1. 深色结构墨建立轮廓和重心。
2. 主体特征色保留地点性格。
3. 环境色提示天空、水、植被或石材。
4. 可选强调色只占很小面积。

必须出现真实手工痕迹：压力不均、缺墨、断边、纸张透底、针孔、干涩颗粒、雕刻线的轻微迟疑、局部积墨，以及克制的 1–2 mm 套印偏差。

## 文字系统

- 标题：1–3 个英文单词，小型大写复古打字机体、窄衬线体或铅字体。
- 关键词：三个短词，以斜杠分隔，例如 `stone / tide / wind`。
- 年份：默认使用当前年份；用户指定年份时使用指定年份，不猜测照片拍摄年份或历史年份。
- 颜色：褪色炭黑或深灰，允许轻微压力不均。
- 位置：紧接章印下方。小版中标题、关键词和年份全部左对齐，文字块左边缘与章印左边缘对齐；大版中三行文字整体居中。

文字用于归档，不用于装饰。地点不可靠时使用泛化主题，禁止猜测地点。
